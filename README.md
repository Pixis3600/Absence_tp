# Gestion des absences

Ce site permet de gérer les demandes d'absence au sein d'une organisation.

Les utilisateurs peuvent consulter leur profil, soumettre une demande d'absence, suivre son statut et voir les informations liées aux congés. L'administrateur a un accès complet pour valider ou refuser les demandes et superviser l'ensemble des absences.
